# Reporting a vulnerability

Send sensitive reports privately through this repository's **Security → Report a vulnerability**
form. If the private form is unavailable, contact a maintainer privately before sending details.
Do not put credentials, customer data or an exploitable reproduction in public issues.

Include the affected example, commit, expected behavior, actual behavior and a minimal reproduction
using synthetic data. Redact all keys and personal data. Nonsensitive usability issues can be public.
